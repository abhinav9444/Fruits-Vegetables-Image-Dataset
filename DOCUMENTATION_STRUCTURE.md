# Documentation Structure

- `README.md` — master dashboard and repository documentation.
- `vegetables/README.md` — vegetable-specific catalog and image workflow.
- `fruits/README.md` — fruit-specific catalog and image workflow.
- `grains/README.md` — grains/cereals/pulses-specific catalog and image workflow.

The three catalogs intentionally use the same metrics model:

**unique items ≠ total photos**

One catalog item can have unlimited photos.
